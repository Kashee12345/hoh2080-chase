# Dr. Aggrawal's Evidence Chase

Practice game for **HOH 2080 · Holistic Health, Wellness and Medicine** (Vermont State University Online).
Outrun seven rivals, one for each chapter of the companion text *The Other Doors* (The Definition, Abraham Flexner,
The Equivocation, The Waitlist, The Sham, The Confounder, The Natural Kind), and the exam chaser Compared With What,
across 280 questions written from the companion text. The game questions are separate from the weekly quiz and
final exam questions.

Play: https://kashee12345.github.io/hoh2080-chase/

Companion text: https://kashee12345.github.io/hoh2080-companion-text/

The main menu has a round for every chapter, two quiz prep chases (Chapters 1 to 3 and 4 to 6), a final chase across
all seven chapters, a daily challenge, an adaptive review, an Evidence Lab matching minigame, a timeline sprint and a
bestiary. Ungraded. Play it as often as you like.

Single self contained HTML file. No login, no tracking; progress is stored only in your own browser.
